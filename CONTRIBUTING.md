# 🛠️ Contribution to this ONIMODs Project

We sincerely appreciate your interest in contributing to the ONIMODs project. Your participation is invaluable to the continued success and maintenance of these modifications.

You can contribute to this project primarily by **raising issues** and **submitting Pull Requests (PRs)**.

## 📝 Core Contribution Needs

Reporting issues is a highly effective and appreciated way to contribute to this project.

Please note that the main maintainer of this project is **not fluent in languages other than Korean**. Therefore, contributions that involve translating documents, code comments, or general text into other languages—especially English—are an **extremely significant help** for the project's maintenance.

Alternatively, if you possess strong communication skills in Korean, you can also contribute by managing the community for our Steam Workshop items or operating the Discord channel (which will be opening soon!).

### Contributing to Code

We value your interest in contributing code, however, **we are not currently accepting code PRs for feature development or bug fixes.**

This policy is temporary. We must first establish an official Code of Conduct and a comprehensive Coding Style Guide to ensure maintainability and quality across all submissions. We plan to open up code contributions soon!
